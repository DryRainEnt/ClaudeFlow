👑 Claude Pro/Team 구독
Claude Pro 또는 Team 구독이 있는 경우 브라우저 로그인으로 인증합니다. 가장 편리하고 안정적인 방법입니다.
권장
🔑 Anthropic API 키
Anthropic Console에서 발급받은 API 키를 직접 입력합니다. 구독이 없거나 독립적으로 관리하고 싶을 때 사용합니다.
대안
Anthropic Console (console.anthropic.com)에서 발급받은 API 키를 입력하세요. 키는 안전하게 암호화되어 로컬에 저장됩니다.
