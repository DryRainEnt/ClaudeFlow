# 🧚‍♀️ Fairy Assistant

**바탕화면에 사는 나만의 AI 비서**

---

## 🎯 프로젝트 개요

Fairy Assistant는 **세계 최초의 바탕화면 거주형 AI 비서**입니다. 사용자의 바탕화면에 작은 집을 짓고 거주하는 요정 형태의 AI가 실제 파일/폴더와 상호작용하며, 개인화된 도움을 제공합니다.

### ✨ 핵심 특징
- 🏠 **바탕화면 상주**: 투명 오버레이로 다른 앱을 방해하지 않음
- 🧚‍♀️ **살아있는 캐릭터**: 실제 폴더에 점프하고 파일을 정리
- 🧠 **개인화 AI**: Claude Code SDK + Greeum으로 사용자별 학습
- 🎨 **무제한 커스터마이징**: 외형, 집, 성격까지 완전 개인화
- 👥 **소셜 기능**: 다른 사용자의 페어리와 교류 (프리미엄)

## 🛠️ 기술 스택

| 분야 | 기술 |
|------|------|
| **플랫폼** | Electron (크로스플랫폼) |
| **프론트엔드** | React + Vite + TailwindCSS |
| **AI 엔진** | Claude Code SDK + Greeum |
| **그래픽스** | Canvas 2D + WebGL |
| **데이터** | SQLite + 클라우드 동기화 |

## 🎮 사용자 경험

### 일상적인 순간들
```
🌅 아침: 페어리가 집에서 나와서 "좋은 아침!" 인사
📁 파일 생성: 호기심으로 다가가서 "새로운 파일이네요!"
🗂️ 정리 요청: "이 폴더 정리해줘" → 폴더로 점프해서 정리
😴 밤: 집으로 돌아가서 불 끄고 잠들기
```

### 상호작용 방식
- **클릭**: 간단한 대화 및 명령
- **드래그&드롭**: 파일 정리 도움 요청  
- **음성**: "안녕, 페어리!" (향후 지원)
- **제스처**: 화면 흔들기 등 재미있는 반응

## 🚀 시작하기

### 개발 환경 설정
```bash
# 저장소 클론
git clone https://github.com/DryRainEnt/ClaudeFlow.git
cd ClaudeFlow

# 의존성 설치 (향후 M1 개발 시)
npm install

# 개발 서버 실행 (향후)
npm run dev
```

### Greeum 메모리 백업
```bash
# 대화 내역 백업
./backup-greeum-memory.sh
```
