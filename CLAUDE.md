## External Context Storage
- Connected GreeumMCP as an external MCP tool to serve as a context storage repository
- Future interactions will involve reading and appending memories to this external storage system

## Project Management Requirements
- 각 마일스톤 단계에 대해 작업 현황을 파악할 수 있는 체크리스트 작성하고, 각각의 마일스톤 작업이 완료될 때마다 [미개시/작업중/완료됨] 순서로 변경되어 업데이트 될 수 있도록 해야 함.
